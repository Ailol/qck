# qck.web

Portable remembered web state.

The web equivalent of qck.dev: keep the durable web state remote, materialize only what is needed locally, and restore the same web world across machines or sessions.

```text
qck.web
├─ browser
├─ profile
├─ extensions
├─ settings
├─ sessions
├─ storage
├─ artifacts
└─ state
```

Remote is durable. Local is the mirage used for processing.
