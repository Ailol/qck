# qck.dev

> all that a dev needs.

Portable remembered development state.

The durable state can live remotely while the local machine materializes a temporary working mirage and borrows local CPU/GPU for processing.

```text
qckdev .    = enter
qckdev down = sleep + remember
qckdev up   = publish latest state
```

VS Code is the first studio pollen: profile, extensions, versions, settings, keymap, layout, executables, runtimes, tools, artifacts and the state that defines the dev world.
